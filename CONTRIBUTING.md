# Contributing to Student Readiness Web App

Thank you for your interest in contributing to the Student Readiness Web App!

## Be Kind

We are committed to providing a welcoming, friendly, and inclusive experience for everyone. Please be kind, respectful, and considerate to fellow contributors and maintainers.

## How to Report Bugs

Before reporting a bug, check existing issues to see if the problem has already been identified.

If you encounter a new bug, please open an issue using the Bug Report template and provide:
- A clear, descriptive title.
- Steps to reproduce the bug.
- The expected behavior and the actual behavior observed.
- Relevant log output, error messages, and system/environment details.

## Pull Request Checklist

Before submitting a pull request, please verify the following:

- [ ] Branch is based on and up to date with `main`.
- [ ] Code follows existing project style and structure.
- [ ] Added or updated tests covering changes.
- [ ] All tests pass successfully (`pytest`).
- [ ] Linter checks pass (`flake8 app tests`).
- [ ] PR description clearly explains the changes and references any related issue.
