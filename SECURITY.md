# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it privately.

**Please do not report security vulnerabilities through public GitHub issues or discussions.**

### How to Report Privately

1. Go to the **Security** tab of the repository on GitHub.
2. Click on **Advisories** and then click **Report a vulnerability** to submit a private security report.
3. Alternatively, contact the maintainers privately via email.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept.
- Any proposed remediation or mitigations if available.

We will review your submission and respond privately as soon as possible.
